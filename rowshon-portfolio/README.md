# Rowshon Ara Sarker - Portfolio Website

A Next.js 14 + Tina CMS + Tailwind CSS portfolio for Rowshon Ara Sarker (Community Organizer, Activist, Film Director, and Writer).

## Getting Started

1. Unzip the project folder.
2. Open the directory in VS Code.
3. Open a terminal and run:
   ```bash
   npm install
   ```
4. Start the development server with Tina CMS enabled:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.
6. Access the visual editor / CMS admin at [http://localhost:3000/admin](http://localhost:3000/admin).

## Hosting on Vercel
1. Push this project to GitHub.
2. Connect your repo on Vercel.
3. Deploy!
